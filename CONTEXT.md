# Polyglow Publishing

Polyglow is a static multilingual editorial site built with Astro. This context
describes the public publishing experience and the people who operate it.

## Language

**Reader**:
A visitor who reads articles, archives, taxonomy pages, and search results.
_Avoid_: End user, consumer

**Site operator**:
A person who maintains content, deployment configuration, and optional site capabilities.
_Avoid_: Admin, developer

**Publishing path**:
The static build and Cloudflare Workers delivery path that turns editorial content into public pages and assets.

**Image delivery strategy**:
The publishing-path rules that generate responsive article, card, and content-image resources for readers.
_Avoid_: Image service tuning

**Optional capability**:
A documented feature that is inactive until the site operator supplies its required configuration.
_Avoid_: Default feature

**Press feedback**:
The immediate visual response to a reader's active press, cancelled gesture, or committed control action.
